02

개인 노트북

세 단계로 적용하기

  1. 01

    비공개 저장소 받기

    GitHub의 tojidi-debug 계정으로 인증한 뒤 저장소를 복제합니다.

    cd "$HOME\Documents"
git clone https://github.com/tojidi-debug/backup.git
cd backup
  2. 02

    변경사항 미리보기

    실제 적용 전에 설치될 지침과 스킬을 확인합니다.

    .\CODEX\scripts\install-on-personal.ps1
  3. 03

    적용하고 다시 시작

    기존 파일은 별도 폴더에 백업됩니다. 완료 후 Codex 앱을 다시 시작합니다.

    .\CODEX\scripts\install-on-personal.ps1 -Apply

!

채팅창 자체는 복원되지 않습니다

주요 대화는 개인정보와 회사 업무 원문을 제거한 인수인계 문서로만 전달됩니다. 동일한 OpenAI 계정 로그인과 GitHub 저장소 인증은 각각 별도로 필요합니다.
